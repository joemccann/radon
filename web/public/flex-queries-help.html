Flex Queries Setup

Two Flex queries power the new TWR Performance. IB_FLEX_NAV_QUERY_ID is required; IB_FLEX_FLOWS_QUERY_ID is optional and falls back to NAV.

1 Flex Web Service Token — IB_FLEX_TOKEN

One token for all Flex queries. Single-quoted if it contains $.

  1. IB Portal → Performance & Reports → Flex Queries → Flex Web Service
  2. Create → copy token → Save
  3. Set in .env, web/.env, Hetzner /home/radon/radon-cloud/.env, and Vercel env: IB_FLEX_TOKEN='…'

Already have one? Current example IDs are 1422766 (trades) and 1497709 (NAV) — reuse the same token, do not create a second.

2 NAV Query — IB_FLEX_NAV_QUERY_ID (required)

  1. IB Portal → Performance & Reports → Flex Queries → Activity Flex Queries → Create
  2. Period: Last 365 Calendar Days · Format: XML · Include: Net Asset Value (NAV) in Base (Report Date, Total), Cash Transactions (Type, Amount, Report Date), Transfers (Report Date, Type, Direction, Cash Transfer, Position Amount in Base)
  3. Save → list shows new row → copy Query ID (e.g. 1497709)
  4. Set IB_FLEX_NAV_QUERY_ID=1497709 in same envs as above
Example — .env
IB_FLEX_NAV_QUERY_ID=1497709
Fallback
If builder finds no NAV rows → insufficient_data empty state (no crash)

3 Flows Query — IB_FLEX_FLOWS_QUERY_ID (optional)

scripts/perf_twr_builder.py uses flows_qid = IB_FLEX_FLOWS_QUERY_ID or IB_FLEX_NAV_QUERY_ID — if your NAV query already includes CashTransactions + Transfers, skip this step.

  1. Same Create flow → only Cash Transactions + Transfers (add Net Asset Value (NAV) in Base if you want it standalone)
  2. Save → copy ID → set IB_FLEX_FLOWS_QUERY_ID=… (leave unset to reuse NAV)

Do not reuse IB_FLEX_QUERY_ID=1422766 (trades) for NAV/flows — that query lacks the sections and will return insufficient_data.

4 FRED — FRED_API_KEY (risk-free)

Sharpe/Sortino use daily 3-mo T-bill (DGS3MO), not 0.

  1. Visit fred.stlouisfed.org/docs/api/api_key.html → Request API Key
  2. Set FRED_API_KEY='…' in same envs (cached to data/risk_free_rate.json; fallback 0 with warning if unset)

Apply & verify

  1. Restart ib_realtime_server / uvicorn or redeploy Vercel.
  2. python3 scripts/perf_twr_builder.py --json | head — should emit curve_type: twr_modified_dietz_daily (not insufficient_data).
  3. Open Performance in the sidebar (now visible on desktop + mobile) — curve starts at first NAV date, metrics gated: Annualized ≥20 sessions, Beta/Alpha ≥40, VaR ≥60.

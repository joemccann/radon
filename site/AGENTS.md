- **Design**: the "Editorial Quant Research" direction (chosen 2026-06-25 from `../marketing-mockups/` 01-brutalism / 02-editorial[chosen] / 03-luxe). Light-first research-journal aesthetic; Newsreader serif + IBM Plex Mono. The mockup `../marketing-mockups/02-editorial/index.html` is the design source; this is the production port.
- **Conventions**: components/{atoms,molecules,organisms,sections}, named exports, `@/` alias, Tailwind v4 `@theme` tokens in `app/globals.css` reconciled onto the existing palette (no parallel system), `next/font`, the existing `lib/theme.ts` theme system (default dark, light toggleable), `"use client"` only where stateful. Preserve SEO infra (`lib/seo.ts` SITE_NAME stays "Radon Terminal").
- **Product plates** (`components/molecules/ProductPlate.tsx`, `public/plates/`): real app screenshots captured via the chrome-cdp skill (debug Chrome :9222, new tab, close after). Anonymize username to `radon-user` via a DOM re-applier (survives React re-renders). Capture light+dark pairs (~1512×862); swap via `[data-theme]`. Cookie-gated newsfeed images need an image-load wait (poll naturalWidth>0 + reset the feed-rail scrollTop). The portfolio plate is a RECREATION (`../marketing-mockups/portfolio-recreation.html`) with fabricated-but-consistent numbers, not a capture. Source copies in `../marketing-mockups/shots/`.
- **⛔ PII**: anonymizing the username does NOT anonymize the data. The dashboard plate still shows REAL account FIGURES (net liq, P&L, positions). Swap account-figure plates to demo data before any public deploy.
- **⛔ Deploy**: Vercel (root `site/`); `vercel.json` ignoreCommand builds only when `site/` changed. `git push origin main` with a `site/` change AUTO-DEPLOYS radon.run publicly. radon.run is operator-only (`feedback_no_radon_run_prod_deploy`) — clear the PII rule first.

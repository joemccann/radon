# Task archive

Completed session checklists rotate here so `tasks/todo.md` stays the
live graph. `tasks/lessons.md` stays at `tasks/lessons.md`.

- `todo-<YYYY-MM>.md`: the `tasks/todo.md` sections whose checklist was
  fully checked when they were rotated, in their original order. Sections
  with any open item stay in `tasks/todo.md`.
- The other files are finished one-off task plans (every box checked, or an
  explicit shipped status), kept for the source comments that cite them.

History, not current truth. Do not put runtime code here.

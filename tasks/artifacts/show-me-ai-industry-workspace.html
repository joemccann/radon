Adversarial Review

Strict Red Lines & System Guardrails

Non-negotiable constraints enforced by the Adversarial Auditor to maintain mathematical rigor and trading safety.

NO SYNTHETIC DATA IN TURSO

Turso is an append-only provenance store with sha256 checksums. Inserting fake rows poisons audit trails and permanently distorts statistical calculations (growth rates, geometric price relatives).

MISSING VALUES ARE NOT ZERO

Zero is a measurement. If a provider is down, an SEC filing unreleased, or an API call unconfigured, the system reports unavailable. It NEVER substitutes zero or interpolates missing points.

NO SPECULATIVE STATUS PROMOTIONS

Indicators cannot be relabeled as "Available" without satisfying mathematical verification (validated_transform=True). Masking incompleteness creates false certainty for trading decisions.

STRICT 900KB PAYLOAD CEILING

The snapshot serialization budget is strictly 900KB. Compact decimation preserves global extrema while preventing Hrana 4-second query timeouts across direct-to-cloud connections.

# Support

Radon is an open-source (Apache-2.0 OR MIT), single-operator trading system.
Clones are unsupported. There is no community, no SLA, and no third-party help
channel.

| Need | Where |
|---|---|
| Operator implementation work | GitHub issue with the `factory` template (label `factory`) |
| Security report | [SECURITY.md](SECURITY.md) |
| Operator runbook | [CLAUDE.md](CLAUDE.md) |
| Operations | [docs/operations.md](docs/operations.md) |
| Documentation index | [docs/README.md](docs/README.md) |

Do not file public issues for vulnerabilities, credentials, or live
account figures.

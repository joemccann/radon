03 / The bootstrap tax is a lock ordering bug

Chicken and egg, not "we forgot Docker"

bootstrap-control-plane.sh installs 21 root-owned files (helpers, sudoers, polkit, and core units including api, relay, monitor, health, gateway, refresh, portfolio-sync, db-backup, drift-audit, nextjs-db-watchdog). deploy.sh preflight requires those installed hashes to equal the incoming SHA before it will promote the release. Change radon-api.service, push, and CI correctly refuses. You then SSH as root, fast-forward /home/radon/radon, run bootstrap, and rerun CI. That loop is load-bearing. It is also unfinished automation: radon-deploy-root has install-units and sync-scheduled-units, and it does not have refresh-control-plane.

05 / Adversarial analysis of the naive plan

Kill shots. Confidence: high unless noted.

K1 2FA
Compose restart policy cannot hold a push lock.

Gateway restart: "no" is not a style choice. IBC relogin, Docker on-failure, and willfarrell/autoheal all mint a second IBKR push while the first is in flight. IBKR then rejects every approval. The watchdog + 10-minute lease + preheld adapter exist because Docker is the wrong supervisor for that container. Putting Gateway in the same project as api/next means compose up after a code deploy recreates it. Confidence: high. Lived through this.

K2 FATE
One compose file is the cascade-stop bug.

Today, stopping radon-ib-gateway cascade-stops relay and monitor via PartOf=, and Restart=always does not re-fire on a clean stop. radon-health is isolated on purpose: no Requires, no After gateway. A single compose project plus depends_on rebuilds that coupling. Health in the same file is a 502 during every deploy. Confidence: high.

K3 SOCK
Any container with docker.sock is root on a live-order host.

Autoheal was removed 2026-07-02 for exactly this: unpinned image, root-equivalent socket, bypass of the 2FA lease. A "platform" container that starts other containers recreates it. Factory already refuses IB Gateway, docker, and host control of the broker. Confidence: high.

K4 TIMER
systemd timers are the product. Cron-in-Docker is a downgrade.

49 timers encode market hours, catch-up fires, RandomizedDelaySec, TimeoutStartSec budgets (bpi 6900s vs 23:30 catch-up), flock SuccessExitStatus=75, Wants vs Requires (skew2d parked parent). ofelia / supercronic / systemd-in-Docker lose that or nest PID 1. Nested systemd is an anti-pattern this repo already deleted (docker/services removed as decoy, 40cfff2a). Confidence: high.

K5 NOTIFY
Relay and monitor are Type=notify watchdogs, not healthchecks.

Relay WatchdogSec=45 via systemd-notify child. Monitor WatchdogSec=900 keyed to loop progress, not process liveness. Docker HEALTHCHECK is TCP/HTTP and will call a wedged event loop healthy. You can pass NOTIFY_SOCKET into a container. That is systemd wrapping Docker, which is the hybrid plan, not Compose-as-OS. Confidence: high.

K6 NET
Bridge networking breaks the loopback contract.

Caddy, IB_GATEWAY_HOST=127.0.0.1, health :8330, WS bind 127.0.0.1, Tailscale 4001 publish are host-namespace facts. User-defined bridges require extra_hosts, published ports, and a rewrite of Caddy plus IB client code. Host network mode is the only sane Docker networking for this box. Host network plus Compose is just systemd with extra YAML. Confidence: high.

K7 EDGE
Caddy is the never-502 floor. Do not put it in the app project.

/edge-health/ping is a static 200 from Caddy. The public chip and the off-box GitHub probe depend on it. Recreating Caddy to ship a Next image is an edge outage class you currently do not have. TLS material and media.radon.run belong on the host. Confidence: high.

K8 PRIV
Docker does not remove the privileged plane. It hides it.

Someone still owns the engine, the firewall, sudoers, and the first image pull credential. If CI can compose up as a user in group docker, CI is root. You removed required reviewers on the Production environment. Giving that same job docker.sock on the trading host is a privilege escalation you spent a year writing sudoers to prevent. Confidence: high.

K9 IDLE
Oneshot timers are free when idle. 40 always-on containers are not.

Host instance type is not pinned in the live runbook (archive mentioned CPX11; treat as unknown). Playwright + Gateway Java + Next + 40 fat images will OOM a small box. systemd oneshots start, write Turso, exit. Keep that. Confidence: moderate on RAM numbers, high on the shape.

K10 LIE
The repo already tried the containerized scheduler and deleted it.

docs/cloud-services.md still advertises docker/services/ as a Phase 4 alternative. The directory is gone. Commit 40cfff2a called those units decoys. Rebuilding that design is not a strategy. It is amnesia. Confidence: high.

07 / Bulletproof plan

Invert bootstrap. Image the app plane. Leave the broker and the edge alone.

P0 · WEEK 1

Stop the lying docs

Delete the docker/services promise from cloud-services.md. Document the three planes. Expand auto-sync-units.txt from 1 line to every timer-owned oneshot. Drain the drift allowlist by actually installing, not by renewing expiry dates.

P1 · WEEKS 1–3

CI control-plane refresh

Add radon-deploy-root refresh-control-plane. Same transaction as bootstrap (lock, refuse pending gateway/app transition, stage, hash, daemon-reload, no process start/stop, no Gateway touch). App deploys call it from the immutable runner. Sudoers/polkit changes require the reviewed control-plane environment. After this, a normal unit edit is git add + hash bump + push. No root SSH.

P2 · WEEKS 3–5

Move secrets and media

/etc/radon/env 0600 root:radon. /var/lib/radon/media. Stop treating ~/radon-cloud as a place. Keep the file as a compatibility symlink until one green deploy reads the new path. This is independent of Docker and should ship first.

P3 · WEEKS 5–10

Image the app plane

CI builds radon-python and radon-node tagged by git SHA, pushed to GHCR. systemd ExecStart becomes a root-helper docker run --network host --env-file /etc/radon/env. Timers stay systemd timers firing --rm oneshots. deploy.sh pulls, writes /var/lib/radon/release-images.env, restart-managed. Host .venv and bun install on the VPS die.

NEVER

Do not

Gateway in the app project. restart unless-stopped on Gateway. docker.sock in any radon image. Caddy in Compose. Health in the trading project. k3s/Nomad/Coolify. systemd inside a container. Laptop forced onto prod images. Factory touching this path.

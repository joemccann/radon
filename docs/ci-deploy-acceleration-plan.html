P0 / CI gate

Isolate cross-tree contracts

A two-line web change triggered the entire Python and cloud suite because broad static guards read parts of web/. Move those guards into a small explicit contract job, keep fail-closed path ownership, and run the full suite nightly.

Save 120–135s on web-only pushes
P0 / Test balance

Remove test-only wall-clock waits

Two weekend-wrapper regression cases each wait about 76s. Add a test-only minimum-remaining-time override, keep the real subprocess and process-group assertion, and run the same boundary with a 1–2s cap. Then isolate Caddy's intentional 30s waits from the remaining cloud tests.

Save 145–150s, then 60–70s
P0 / Deploy

Gate exact images, pull in parallel

Container drop-ins are active, but deploy blocks for about 79s after prestage and can fall back to latest. Build exact-SHA images during tests, pull them in a gated job parallel to prestage, then require a fast local exact-SHA check before teardown.

Save 65–80s on every deploy
